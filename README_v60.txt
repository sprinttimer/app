Sprint Timer Pro v60 — 2026-10-02

使い方
1. ZIP内の index.html はアプリ全体の完成コードです。
2. GitHub Pagesで更新する場合は、既存の index.html をこのファイルで差し替えます。
   manifest.json、sw.js、アイコンなどの既存ファイルはそのまま併用します。
3. 起動後、バージョンが「2026.10.02.60」になっていることを確認してください。
   古い表示の場合は、ブラウザの再読み込みとPWAの再起動を行ってください。
4. 接地一覧の「見る」で、一覧直上の確認映像を開きます。
   「前の接地／次の接地」「1F／5F」「接地へ／離地へ」で切り替えられます。
5. 接地開始と離地は別々に指定します。自動推定した離地は「手動確定」にはなりません。
6. 目視で全接地を指定した場合は、「接地の採用」を「手動指定だけ」に切り替えられます。
   初期設定は「自動＋手動修正」です。動画ごとに歩数を固定していません。

主な変更
・STARTの接地判定を、足ごとの空中→接地→離地の連続した区間に集約。
・つま先が接地中なら、かかと・足首が上がっても離地扱いにしない。
・足部の1フレームの揺れや、補間した点だけで新しい接地を作らない。
・手動指定と同じ接地区間の自動候補を統合。
・削除した区間の自動候補の再出現を防止。
・手動接地の時刻、手動離地、左右の確認状態を分離。
・接地一覧内の共通確認映像、コマ送り、半速の前後再生、選手拡大を追加。
・現在表示中のフレームと、角度測定に採用したフレームを区別して表示。

対象と検証
今回の接地判定変更はSTART解析が対象です。人体検出・人体追跡の主要処理と、
Sprint解析／VBT／MyJumpの解析処理は維持しています。
全37個のインラインJavaScriptの構文確認、11件の接地判定テスト、
7件の統合・確認画面の操作処理テスト（DOM・動画を模擬）を通過しました。
実ブラウザによる描画確認、Androidでの操作、添付動画のPose再解析は未実施です。
4歩へ強制的に合わせたコードではありません。実動画での自動歩数は再確認が必要です。

通信・起動条件
人体検出の外部ライブラリ読込と起動条件はv59と同じです。
HTMLだけをダウンロードして開く場合も、初回はライブラリ読込が必要です。
今回の改修では動画の外部送信処理を追加していません。
